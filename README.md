# Módulo 5 Unidad 2 - Introducción al lenguaje SQL (UTN)
Resolución de las 14 consultas solicitadas sobre la tabla `empleados`:
- Consultas `SELECT` con filtros `WHERE`, `AND`, `OR`, `BETWEEN` y `LIKE`.
- Inserción de registro con `INSERT INTO`.
- Eliminación con `DELETE FROM`.
- Actualización con `UPDATE ... SET`.
Todas las sentencias se encuentran detalladas en el archivo `consultas.sql`.
